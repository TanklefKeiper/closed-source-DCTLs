Changes in V01:
- There is an added slider that lets you shift the targeted hue zones.
  Before, if you wanted to target skin tones for example, it was a bit awkward because they sit inbetween red and yellow. Now you can just
  tweak the shift-zones slider a bit so that either the red or yellow zone targets the skintones better. (This also works well for the green of plants
  that are almost never pure green but with a large yellow component.)
  The slider shifts all zones equally meaning that they also maintain their width which increases smoothness. Not like with the Color Slice tool
  where the skin tones are awkwardly sqeezed in between red and yellow.
